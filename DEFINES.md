Defines which IrisAdditions adds to shaders.

| Define | Added when | Explanation |
|---|---|---|
| `IS_IRIS_ADDITIONS` | IrisAdditions is installed | |
| `IRIS_ADDITIONS_VERSION` | IrisAdditions is installed. The value is its version as a number, 0.1.0 is `100` and 1.2.3 is `10203` | |
| `IRIS_ADDITIONS_AT_MIDBLOCK_FIX` | IrisAdditions applies the fix | [at_midBlock at High Coordinates](BUG_FIXES.md#at-midblock-fix) |
