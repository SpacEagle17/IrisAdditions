A feature turns itself off if your Iris version already has it.

| Feature                                                 | What it does                                                                                                                                                                                                                                          | Minecraft      | Credit                                                                                                                                     |
|---------------------------------------------------------|-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|----------------|--------------------------------------------------------------------------------------------------------------------------------------------|
| <a name="dh-textures"></a>**Distant Horizons Textures** | Shaders can use block textures on Distant Horizons terrain through `dh_hasTexture()` and `dh_sampleTexture()`, like in newer Iris. Needs Distant Horizons 3.3.0 or newer. Shaders can check for the define [`DISTANT_HORIZONS_TEXTURES`](DEFINES.md). | 1.20.1-26.2    | [Iris commit 5b89e91](https://github.com/IrisShaders/Iris/commit/5b89e916bf228b202e8b8b26df6742149be3b954) by IMS                          |
| **Uniform Backports**                                   | Shaders can use uniforms of newer Iris versions, see the [uniform list](UNIFORMS.md).                                                                                                                                                                 | 1.20.1-26.2    | Credited per uniform in the [uniform list](UNIFORMS.md)                                                                                    |
| <a name="more-color-buffers"></a>**More Color Buffers** | Shaders can use 32 colortex's(0-31), instead of 16, like in newer Iris. Shaders can check for the define [`MAX_COLOR_BUFFERS`](DEFINES.md). Changing this needs the game to be restarted.                                                             | 1.20.1-1.21.11 | [Iris commit b7c084d](https://github.com/IrisShaders/Iris/commit/b7c084d24c542a1f2c9982ed75fd6225ef471af3) by IMS                          |
| **More Storage Buffers**                                | Shaders can use SSBOs up to 12 instead of 8, like in newer Iris.                                                                                                                                                                                      | 1.20.1-1.21.11 | [Iris commit aaafb02](https://github.com/IrisShaders/Iris/commit/aaafb02916b7bf27276c10d76d739e3ee473a6b2) by IMS                          |
| **Clamped End Flash Angle**                             | With shaders, the End flash always appears at least 5 degrees above the horizon like in newer Iris, so its shadows stay stable.                                                                                                                       | 1.21.9-26.2    | [Iris PR #3082](https://github.com/IrisShaders/Iris/pull/3082) by Acer (Alex) and IMS                                                      |
| **Drop Settings in Selection Screen**                   | A shader settings file can be dropped directly into the shader selection list to import it into the active shaderpack, without opening its settings first.                                                                                            | 1.20.1-26.3    | IrisAdditions, SpacEagle17                                                                                                                 |
| **Shorter Hover Time**                                  | The description of a shader setting appears after half a second of hovering instead of a full second.                                                                                                                                                 | 1.20.1-1.21.11 | [Iris commit 67e291c](https://github.com/IrisShaders/Iris/commit/67e291c518cd3bd7b6393bb9a00c60c8f64d6e42) by SpacEagle17, yes, that be me |
| **Hide GUI Keybind**                                    | F1 hides and shows the GUI of the shader pack screen, just like its button.                                                                                                                                                                           | 1.20.1         | [Iris commit ce16652](https://github.com/IrisShaders/Iris/commit/ce1665241b52e7f90bd8a7c57624f11d630df934) by IMS                          |
